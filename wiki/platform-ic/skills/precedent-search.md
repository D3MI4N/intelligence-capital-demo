# Precedent search before appetite positions

When to apply: any new submission, before drafting an appetite position.

1. Query the knowledge base for the risk class and peril focus - meaning
   search, not just the insured's industry label.
2. Traverse the graph from the risk class entity: prior cases, exclusions
   applied, lessons attached. Two hops minimum.
3. Read the lessons.md of every prior case surfaced, not only briefings -
   lessons carry what the briefing missed at the time.
4. Cite what you found or state explicitly that no precedent exists.
